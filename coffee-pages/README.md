# Кофе Ягоды — сайт кофейни

Одностраничный сайт для кофейни «Кофе Ягоды» (Ставрополь, ул. Бруснёва, 11Б).

## Как открыть

Откройте `index.html` в браузере — сборка не нужна, всё статическое.

Если нужен локальный сервер (например, для корректной работы шрифтов и относительных путей):

```powershell
cd D:\youtube\coffee
python -m http.server 8080
# затем http://localhost:8080
```

## Структура

```
coffee/
├─ index.html          — вся разметка и SVG-иллюстрации
├─ assets/
│  ├─ css/style.css    — стили, анимации, адаптив
│  ├─ js/main.js       — шапка при скролле, появление блоков, параллакс
│  └─ img/og.jpg       — картинка для соцсетей
└─ shot-*.png          — превью (не часть сайта)
```

## Что где менять

- **Тексты, цены, состав меню** — в `index.html`, блоки `<section id="menu">` и `<section id="bakery">`.
- **Контакты, часы, телефон** — `<section id="contacts">` и `<footer>`.
- **Отзывы** — `<section id="reviews">`. Сейчас там два реальных отзыва с Яндекс.Карт и карточка с рейтингом.
- **Цвета** — переменные в начале `assets/css/style.css` (`--cream`, `--berry`, `--caramel` и т. д.).
- **Анимации** — блок `@keyframes` в конце CSS. При `prefers-reduced-motion` всё отключается автоматически.

## Важное о контенте

- Цены на кофе (220–300 ₽) — ориентировочные, их нужно сверить с актуальным меню. Позиции выпечки (чизкейк 275 ₽, сырники 320 ₽, сэндвич 370 ₽, клубника в шоколаде от 2 070 ₽) взяты из карточки на Яндекс.Картах.
- Часы работы: 08:00–21:00 (по данным карточки; в некоторых справочниках указано иное — стоит уточнить).
- Отзывы приведены с Яндекс.Карт; третий блок — не отзыв, а сводка рейтинга.

## Технические детали

- Шрифты: Playfair Display + Manrope (Google Fonts). Без интернета подставится Georgia / системный шрифт.
- Иллюстрации — inline SVG, поэтому масштабируются без потерь и не требуют картинок.
- Пена в шапке — SVG с goo-фильтром (`feGaussianBlur` + `feColorMatrix`) и медленной анимацией пятен; она «растекается» по карточкам товаров.
- Повидло на булочках — SVG-капли с анимацией `drip` / `dropFall`.
